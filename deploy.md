# Deployment Guide (Ubuntu/Debian VPS)

This guide explains step-by-step how to deploy the **Free Panels Servers** application on a VPS (Virtual Private Server) running Ubuntu or Debian, using a domain name, Nginx (Reverse Proxy), and an SSL certificate (HTTPS) via Certbot.

## Prerequisites
- A VPS running **Ubuntu 20.04 / 22.04 / 24.04** or Debian.
- A **domain name** (e.g., `mydomain.com`) pointing to your VPS IP address (A Record).
- SSH root access or a user with `sudo` privileges.

---

## Step 1: System Preparation

Connect to your VPS via SSH and update the packages:

```bash
sudo apt update && sudo apt upgrade -y
```

Install the required dependencies (Git, Nginx, Certbot):

```bash
sudo apt install -y git nginx certbot python3-certbot-nginx
```

Install **Node.js** (version 20 recommended):

```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
```

Verify the installation:
```bash
node -v
npm -v
```

Install **PM2**, a process manager to keep the application online 24/7:
```bash
sudo npm install -g pm2
```

---

## Step 2: Fetching the Project

Clone your project onto the VPS (replace the URL with your Git repository URL):

```bash
cd /var/www
sudo git clone https://github.com/your-username/your-repo.git free-panels
cd free-panels
```

*(If you are not using Git, you can transfer the files via SFTP/FileZilla into the `/var/www/free-panels` folder)*

Grant the necessary permissions to your user (replace `ubuntu` with your username if different):
```bash
sudo chown -R $USER:$USER /var/www/free-panels
```

Install the project dependencies:
```bash
npm install
```

---

## Step 3: Environment Configuration

Copy the example file to create your configuration file:

```bash
cp .env.example .env
nano .env
```

Fill in the variables with your production information:
- `PTERODACTYL_URL`: The URL of your Pterodactyl panel (e.g., `https://panel.mydomain.com`).
- `PTERODACTYL_ADMIN_API_KEY`: Application API Key (Admin) generated on Pterodactyl.
- `PAYPAL_CLIENT_ID` and `PAYPAL_CLIENT_SECRET`: Your PayPal credentials (Live).
- `DEXPAY_API_KEY`: Your Dexpay API key for Mobile Money payments.

Save and exit (`Ctrl+O`, `Enter`, `Ctrl+X`).

---

## Step 4: Build and Launch (PM2)

Compile the frontend (React/Vite) for production:

```bash
npm run build
```

Start the backend server with PM2:

```bash
pm2 start npm --name "fps-app" -- run start
```

Save the PM2 configuration so the application restarts automatically if the VPS reboots:

```bash
pm2 save
pm2 startup
```
*(Run the command generated by `pm2 startup` if prompted).*

---

## Step 5: Nginx Configuration (Reverse Proxy)

We will configure Nginx to redirect web traffic (port 80/443) to our Node.js application (port 3000).

Create a new Nginx configuration file:

```bash
sudo nano /etc/nginx/sites-available/free-panels
```

Paste the following configuration (replace `mydomain.com` with your actual domain name):

```nginx
server {
    listen 80;
    server_name mydomain.com www.mydomain.com;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

Enable the site and test the Nginx configuration:

```bash
sudo ln -s /etc/nginx/sites-available/free-panels /etc/nginx/sites-enabled/
sudo nginx -t
```

If the test is successful, restart Nginx:
```bash
sudo systemctl restart nginx
```

---

## Step 6: Securing with SSL (Certbot / HTTPS)

Generate a free SSL certificate with Let's Encrypt to secure your site with HTTPS:

```bash
sudo certbot --nginx -d mydomain.com -d www.mydomain.com
```

Follow the on-screen instructions:
1. Enter your email address.
2. Accept the terms of service (A).
3. Choose whether you want to share your email (Y/N).
4. Certbot will automatically modify your Nginx configuration to force HTTPS.

Verify that automatic renewal is active:
```bash
sudo systemctl status certbot.timer
```

---

## 🎉 Done!

Your application is now online, secured with HTTPS, and accessible via your domain name!

### Useful Commands for Maintenance:

- **View application logs:** `pm2 logs fps-app`
- **Restart the application:** `pm2 restart fps-app`
- **Update the application:**
  ```bash
  cd /var/www/free-panels
  git pull
  npm install
  npm run build
  pm2 restart fps-app
  ```

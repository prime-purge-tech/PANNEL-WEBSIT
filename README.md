# FREE PANELS SERVERS 🎁

FREE PANELS SERVERS is a free hosting panel.

## Features
- Automatic server creation on Pterodactyl.
- Automatic resource management.
- No time limits.

## Configuration
1. Copy `.env.example` to `.env`.
2. Fill in the environment variables with your Pterodactyl information.
3. Install dependencies: `npm install`.
4. Start the server: `npm run dev`.
